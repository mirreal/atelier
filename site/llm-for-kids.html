01 · 亲手玩一玩

来，和小语一起猜下一个字

你给它一句话的开头，它会算出「接下来最可能是哪个字」，然后选一个接上去——接完再猜下一个。整个大模型做的事，就是这个。

从前有一只小猫
点「接着写」，看看它想接什么。
🌡️ 想象力旋钮（温度）0.7
很保守 · 总选最有把握的很跳脱 · 更有创意
调低：它总挑把握最大的那个字，话很稳但有点重复。调高：它也更愿意选把握小的字，更有意思，但也更容易说错。
⚡ 写字速度中速
慢（看得清）中快
小实验：把「想象力旋钮」拉到最大，再点「再写一次」。你会看到它说的话变得……有点乱？ 这就是同一个模型、同一个开头，只是选字的胆子变大了。
02 · 它为什么猜得准

因为它「读」过好多好多的书

小语不是天生的聪明。它把成千上万本书、网页和文章都读过一遍，默默记住了「这个字后面通常跟什么字」。读得越多，它见过的情况就越多，说出来的话就越通顺。你可以拖下面的滑块，真的改变它读过多少东西。

页面里的这个「小语」

只读了 183 句话。所以你常常看到它说出奇怪的话——这不是 bug，是它读得太少了。

真正的大模型

读过几百万本书、几乎整个互联网上的文字。里面有上千亿个「小旋钮」，每读一句话就调一点点。

为什么它有时会说出不通顺的话？因为小语的见识太少。真正的大模型也是同一个道理，只是它的「见识」大到我们想象不出来——所以听起来才那么像人话。
🤔 给好奇的小朋友：把滑块从最小拉到最大，你会发现一个奇怪的事——它读得越多，对「下一个字」的把握反而没有变得更高，有时还低了一点。 因为它见过的可能性变多了，「下一个字」不再只有一个明显的答案。这在大模型身上也是真的。
03 · 偷偷看一眼它的工作台

它不是一次读「一句话」，
而是一小块一小块

大模型看文字的方式，像把一串乐高拆成小积木。「我喜欢吃草莓冰淇淋」在它眼里不是 11 个汉字那么简单，而是一堆小积木——有的是整个词，有的是半个词，有的是单个字。

为什么要切小块？因为这样它就能处理从来没见过的词了。哪怕「草莓味冰淇淋蛋糕」是个新词，它也能用「草莓」「冰淇淋」「蛋糕」这几块拼出来——就像用积木拼出没见过的造型。
04 · 最重要的部分

它会一本正经地说错

大模型有个毛病，科学家给它起了个名字叫「幻觉」——就是它编了一个听起来很像真的答案。它并不是在撒谎，它只是在「猜字」，而它猜出来的字恰好拼成了一句假话。

亲眼看一下

问小语一个它根本不可能知道的问题，它照样会接下去：

火星上有几只大象在跳舞？答案是

看：它完全不知道答案，可它还是接了下去，而且接得很顺、很自信。真正的大模型也是这样——只是它编出来的话更像真的，更难发现。

小侦探练习：这几句话，该不该再查一查？

05 · 划清界限

它很厉害，但它不是人

理解这一点，你就比很多大人更懂大模型了。

它确实很会 👍

  • 把话说得很通顺、很像人
  • 记住读过的海量知识
  • 几秒钟写完一篇长文章
  • 帮你解释难懂的词、一起想点子
  • 不知疲倦、不会不耐烦

它其实不会 👎

  • 它没有眼睛——没真的看见过小猫
  • 它没有感受——说「我难过」只是在排字
  • 它不会算数——它是在猜数字该长什么样
  • 它不知道今天发生了什么
  • 它不知道自己错了——错了也说得一样肯定
记住这句话：大模型是在排列文字，不是在思考世界。它的话读起来像有想法，其实背后只有一件事：下一个字该是什么。

07 · 用它的正确姿势

和它做朋友的四个约定

?

把它当「很会猜的助手」，不是「什么都知道的老师」

它给的是可能性最大的答案，不是正确的答案。

✓

重要的地方，自己再查一遍

尤其是数字、日期、人名、地名——这些正是它最容易编出来的东西。去书本或正规网站核对一下。

!

别告诉它你的秘密

家里住址、学校名字、密码、真实姓名、照片……这些都不要发给它。就像不要告诉陌生人一样。

★

让它做你做不到的事，而不是替你思考

让它编故事、解释难词、给你的作文提意见、陪你练英语对话。但想法要是你自己的。

给爸爸妈妈 / 老师的话

这个页面里的「小语」不是一个假装出来的动画，而是一个真正跑在浏览器里的字符级三元语言模型（trigram）， 语料是本页内置的一百八十多句话。所以：温度滑块真的在改变采样分布，读书量滑块真的在重建模型，概率条是真实的 n-gram 统计。 它说出的乱话不是 bug，而是「小模型见识太少」的真实写照——这恰好是本页想教的第一件事。 页面零外部依赖，完全离线可用，没有收集任何数据。

概念上做了适合 6–12 岁的简化：真实的 LLM 预测的是 subword token 而非汉字，用的是神经网络而非计数表，参数量在千亿级； 但「预测下一个 token + 采样 + 温度 + 规模决定质量 + 幻觉」这条主线是一致的。
