一次性设置：启用 Drive 同步（约 3 分钟）

出于安全考虑，Google 要求网页在 https 下访问、并使用你自己的 OAuth 客户端 ID，本工具无法内置。
如果即使用分享方式也要配置，可跳过下面 1–4 步，直接点「导出到 Drive（分享方式）」，无需任何设置。

  1. 打开 Google Cloud Console，新建（或选择）一个项目。
  2. 在「API 和服务 → 库」中启用 Google Drive API。
  3. 在「API 和服务 → OAuth 同意屏幕」选择 外部，用户类型填自己即可；把你自己加入「测试用户」。
  4. 在「API 和服务 → 凭据 → 创建凭据 → OAuth 客户端 ID」，类型选 Web 应用；
    「已获授权的 JavaScript 来源」填本页面的地址，例如 https://你的域名 或本机调试用的 http://localhost:8000。
  5. 把生成的客户端 ID 粘贴到下方并保存，然后点「连接 Google Drive」授权。

客户端 ID 会存在本机浏览器里，只用于向 Google 发起授权，不会发往其他服务器。

注意：用 file:// 直接打开本文件时，Google 不允许登录，上面 5 步也无法生效；请把文件放到 https（或 http://localhost）下访问，或改用上面的分享方式。
